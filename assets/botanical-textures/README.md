`wisteria-neutral-atlas-candidate.png` is newly generated original artwork from the built-in
imagegen tool, not copied from the owner's photographs. It is a neutral six-cell albedo study:
leaf front/back, banner, wing, keel and bud tissue. Original1254×1254 RGBA and transparency are
preserved. The image is opt-in only in the private unregistered Wisteria hero review fixture; the production
renderer/catalog does not expose it. Actual atlas-bound native acceptance remains pending.

Generation used botanical anatomical requirements, a two-column/three-row layout, neutral
ivory/grey tissue for shared instance tint, fine veins and no labels/shadows. Fine coloured edge
specks and the exact cutout/UV fit need inspection before any actual material use. This is texture
artwork, not a finished arch image or visual acceptance of the model. Do not duplicate it per
flower palette or per placed decoration.
